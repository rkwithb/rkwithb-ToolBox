# URL Cleaner - 網址去參數捷徑 🚿

這是一個專為 iOS 設計的「捷徑」（Shortcut），旨在分享網址時，自動移除那些用於追蹤使用者行為的冗餘參數（如 `igsh`, `si` 等），保護隱私同時讓網址更簡潔。

## 1. 專案目標 (Goal)

在數位時代，各大平台（如 Instagram, YouTube）會在分享連結中加入追蹤碼。本工具的目標是：

* **保護隱私**：移除連結中可能關聯到個人帳號的追蹤參數。
* **網址美化**：去除長串亂碼，讓分享的連結看起來乾淨專業。
* **一鍵自動化**：透過 iOS 分享表單快速完成，無需手動編輯文字。

## 2. 使用方法 (How to Use)

1. 
**安裝**：將 `cleanURL.shortcut`  檔案下載至您的 iPhone，點擊檔案即可將其加入「捷徑」App。
2. **分享連結**：在 Instagram 或 YouTube 等 App 中點擊「分享」。
3. **執行捷徑**：在分享選單中點擊「更多」，選擇 **「URL Cleaner」**（或您設定的名稱）。
4. **自動完成**：捷徑會自動清洗網址並將乾淨的連結存入您的**剪貼簿**，您可直接貼給朋友。

## 3. 注意事項 (Notice)

* **系統要求**：建議在 iOS 15 或更高版本的環境下使用。
* **權限說明**：執行時捷徑會請求「剪貼簿」取用權限，這是為了讀取並替換網址，請放心允許。
* **短網址限制**：本工具主要針對常見參數進行字串取代。若連結經過多重縮網址（如 bit.ly），可能需要先還原長網址才能完全清洗。

## 4. 如何修改正規表達式 (How to update Regular Expression)

如果您發現有新的參數需要過濾，可以按照以下步驟自行更新：

1. 開啟「捷徑」App，點擊本捷徑右上角的「三個點」進入編輯模式。
2. 找到 **「取代文字」** 動作。
3. 編輯第一個欄位中的 **正規表達式 (Regex)**：
* 目前模式範例：`[?&](igsh|si|xmt|slof)=[^&]+`
* **如何增加新參數**：在括號內使用 `|` 符號隔開。例如想增加 `fbclid`，請改為 `(igsh|si|fbclid|...)`。

4. 確保下方的「正規表達式」開關維持**開啟**狀態。
