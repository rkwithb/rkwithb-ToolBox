## 版本更新說明 (Update Summary)


*   **功能特點**
    *   清理網址、短網址展開以及處理完後自動寫入剪貼簿 (Clipboard) 。

*   **最新第三版修正 (`cleanURLv3.shortcut`)** 20260813 updated
    *   ⚠️ 建議升級到 v3
    *   修正下載後無法存取的權限問題


*   **第二版升級 (`cleanURLv2.shortcut`)** 20260806 updated
    *   **網址還原 (URL Expansion)**：新增對於短網址 (Short URLs) 的支援，能自動追蹤並還原被隱藏的原始長網址。
    *   **隱私強化**：延續並強化過濾機制，確保連結乾淨無追蹤。

*   **舊版概要 (`cleanURL.shortcut`)**
    *   主要透過 **Regular Expression** (正規表達式) 移除網址中常見的社群追蹤參數 (例如 `si`、`feature`、`igsh`、`xmt`、`slof` 等)。
